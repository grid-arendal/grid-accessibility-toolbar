GRID-Arendal 2.0 consolidates accessibility and configurable shared editorial tools as optional modules. Existing installations retain their settings and stable update identity.

Adds display-name overrides for ACF groups, fields and tabs, plus plural/singular content-section labels. Storage keys, values, relationships and URLs are retained.

Optional modules provide a private content workspace, review and activity, validated CSV draft imports, explicit reviewer notifications, private files outside the web root, a coordinate picker and published LearnPress course connections. New editorial modules default off. No roles, legacy plugins or content are automatically migrated. See MODULES.md for setup and migration boundaries.

Keeps the compact admin flower and discreet language reset. The site-specific Beaver Themer header/footer is separate from the reusable plugin.
