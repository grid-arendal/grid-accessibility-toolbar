Adds optional private GitHub release updates, using server-held read-only credentials and the native WordPress update interface.

Only published stable releases with an installable plugin ZIP are accepted. Drafts, prereleases and branch/source archives are excluded. Includes GRID-Arendal → Plugin updates setup/status.

Existing installations need this ZIP installed once and a repository-scoped read credential configured on each server. The reading widget works without private-update configuration. No credential is included in this release.
