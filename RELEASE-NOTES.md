Automatically adds an accessible account icon to a main WordPress menu when the front-end workspace is enabled. Signed-out visitors get a login link returning to the workspace; authorised editors get direct access; other signed-in accounts see no editor icon. Existing workspace links are reused, with a menu selector and opt-out. First enable creates a private workspace page and Page/Article sections if not configured. Existing setups, field customisations and native permissions are preserved.
