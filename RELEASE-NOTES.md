Public release updates without per-website GitHub credentials.

Includes a public release feed, normal WordPress update notices and a GRID-Arendal → Plugin updates status page. The release workflow advertises an update only after its stable installable ZIP has been uploaded and verified. Drafts, development versions, branch/source archives and mismatched package URLs are excluded.

Install this ZIP once on each website. Subsequent releases can be installed through WordPress; automatic installation remains an administrator choice. No access token or website registration is required.
