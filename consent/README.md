# GRID Cookie Consent

Independent, self-hosted WordPress consent plugin, with a native GitHub update channel and reversible integration into a branded GRID Tools menu. No subscription or remote CMP is required.

- Equal Accept/Reject controls, granular purposes and persistent withdrawal access.
- Managed GA4 basic Consent Mode v2 and separate Clarity consentv2; no managed analytics/recording or cookieless vendor pings before consent.
- GPC, consent expiry, policy/configuration renewal and signed local receipt verification.
- Floating or edge-to-edge full-width layouts, instant appearance preview, English/Norwegian and custom local translations.
- Existing-policy selection and editable policy drafts; generation does not publish or certify approval.
- Recognised GRID menus use existing callbacks/capabilities under one branded 20px flower menu. Other plugin files/data are not rewritten. Grouping is reversible without disabling consent protection.

Install the release ZIP. Read [INTEGRATION.md](INTEGRATION.md), [SOURCES.md](SOURCES.md), and [TEST-REPORT.md](TEST-REPORT.md) before rollout. Do not install from GitHub's source archive. WordPress 6.4+, PHP 7.4+ and a modern JavaScript browser are required.

This supports consent-related compliance; it does not guarantee Norwegian/GDPR/global compliance, discover every tracker, replace vendor/controller reviews, provide Google CMP certification, or implement IAB TCF. All optional services stay blocked until setup is reviewed. Existing independent Accessibility/Editorial and legacy combined update feeds are unchanged.
